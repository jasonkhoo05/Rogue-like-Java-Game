    Assignment 3 Req 3 + 4:
     In this creative mode, the game world evolves dynamically with changing weather and environmental conditions that 
     directly influence gameplay.
     The player must adapt to unpredictable weather cycles such as rain, drought, storm, or heatwave, each of which 
     affects actor abilities, terrain behavior, and item interactions.
     This feature adds strategic depth and realism to the existing world by integrating environment-driven challenges 
     and opportunities.
     
     New classes: 
     1) WeatherSystem: Manages global weather states across the map. Associates with World or GameMap from the 
     engine package
     2) WeatherEffect: a common interface for all weather types
     3) TornadoEffect: randomly drag actor to nearby tiles and deals damage to it
     4) HeatwaveEffect: Increases warmth and attacks have fire effect.
     5) StormEffect: Causes lightning strikes that may damage random tiles if no actors are on it, otherwise damage 
     actor and stun it (cannot to move for 3 rounds)
     
     In this creative mode addition, the player can discover and consume special orbs that grant temporary 
     enhancements or protections.
     Each orb lasts for a limited number of turns and can greatly influence combat, movement, or survival depending 
     on the current environment.
     This system adds a layer of strategic resource management, encouraging players to plan when and how to use orbs 
     effectively to survive or gain an advantage.

     New classes:
     1) MagicalOrb: An abstract base class representing all magical orbs. Defines shared attributes such as duration and consumption 
     behavior. Integrates with the Item and Action classes from the engine package.
     
     2) OrbEffect: An interface that defines how magical orbs effects are applied and removed from actors. Each magical orb 
     implements this interface to provide unique functionality.
     
     3) ActivateOrbAction: An action class to activate the magical orb.

     4) SpeedOrb: When consumed, allows the actor to move up to 2 tiles per turn for 5 turns. Useful for quickly 
     escaping danger or crossing large areas.

     5) HeatResistantOrb: Grants the actor immunity to fire damage for 5 turns. Effective on burning 
     terrain.
     
     6) RegenerativeOrb: Restores 1 HP per turn for 5 turns after consumption. Ideal for long battles or survival under 
     damaging weather effects.

    Feature 2 – Recipe Generation upon Food Consumption
        When the player consumes any food item (e.g. Apple, Yewberry), a new recipe will be 
        generated by using RecipeGenerator class. The recipe will include the list of required 
        ingredients and instructions. So whenever a player consumes something, it will first show the 
        ingredients and instructions of the item on console and record in RecipeJournal. Player can read the 
        RecipeJournal, see all the list of recipes of food he consumed and provide an opinion generated
        from AI using TalkAction.

        New classes:
        1. RecipeGenerator
        2. TalkAction 
        3. HasRecipeJournal
        4. ReadJournalAction 
        5. Talkable 

         These two features work together to create a more engaging and meaningful gameplay experience. 
         The Wise Man NPC provides short monologues every 3 rounds, giving hints, lore, and useful information that 
         encourages players to explore and pay attention. Meanwhile, the Recipe Generation system makes food consumption 
         more rewarding. Each time the player eats an item, a unique recipe is revealed, turning simple actions into moments 
         of discovery. Together, they enhance immersion, add progression, and make the game world feel more interactive and purposeful.
